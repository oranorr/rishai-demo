## 🔧 **Ключевые компоненты миграции**

### **1. Конфигурация API (`whoop_api_config.dart`)**
```dart
class WhoopApiConfig {
  // Feature flag для включения v2 API
  static const bool _enableV2Api = false;
  
  // Принудительное использование v2 API
  static const bool _forceV2Api = false;
  
  // Автоматическое определение версии
  static String get apiVersion {
    if (_forceV2Api) return 'v2';
    if (_enableV2Api) return 'v2';
    return 'v1';
  }
}
```

**Преимущества:**
- ✅ Плавное переключение между версиями
- ✅ Безопасное тестирование v2
- ✅ Быстрый rollback при проблемах
- ✅ Feature flag для A/B тестирования

### **2. Менеджер миграции (`whoop_api_migration_manager.dart`)**
```dart
class WhoopApiMigrationManager {
```
