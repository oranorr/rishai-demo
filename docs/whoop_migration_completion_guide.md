## 🔧 **Инструменты для мониторинга**

### **1. Менеджер миграции**
```dart
// Получить информацию о миграции
final migrationInfo = whoopMigrationManager.getMigrationInfo();
print('Migration status: $migrationInfo');

// Проверить готовность
final ready = whoopMigrationManager.checkMigrationReadiness();
print('Ready for migration: $ready');
```

### **2. Логирование**
Все ключевые операции логируются с префиксом:
```
WHOOP API v2 Migration: [Operation] [Details]
```

### **3. Конфигурация API**
```dart
// Проверить текущую версию
print('API Version: ${WhoopApiConfig.apiVersion}');
print('Migration Status: ${WhoopApiConfig.migrationStatus}');

// Получить полную информацию
print('Config: ${WhoopApiConfig.configInfo}');
```
